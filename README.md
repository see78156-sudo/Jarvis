# جارفيس

مساعد ذكي بالعربي، تطوير سيف إسلام.

## النشر على Render
1. ارفع كل الملفات دي على مستودع GitHub جديد.
2. في Render اختار New > Web Service، واربطه بالمستودع.
3. Build: `pip install -r requirements.txt` و Start: `python server.py`.
4. من Environment ضيف متغير اسمه `GEMINI_API_KEY` وحط فيه مفتاحك الجديد.
5. بعد ما ينشر هتاخد رابط، افتحه وجرب.

## حدود الاستخدام (تتغير من Environment)
- `PER_IP`: عدد الرسايل لكل شخص (الافتراضي 20)
- `WINDOW`: خلال كام ثانية (الافتراضي 600)
- `DAILY`: الحد اليومي لكل الناس (الافتراضي 800)
